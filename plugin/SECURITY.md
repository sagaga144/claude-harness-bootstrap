# Security

This plugin generates hook scripts and settings that run inside Claude Code on your
machine. If you find a way a generated harness could run something you didn't intend,
leak a secret, or skip a guard it claims to enforce, please report it privately.

**Report it privately:** go to the
[Security tab](https://github.com/sagaga144/claude-harness-bootstrap/security) and click
**Report a vulnerability**. Please don't open a public issue for security problems.

Include the project description you used, the generated file involved, and what happened.
I'll reply as soon as I can and credit you in the fix unless you'd rather not be named.
